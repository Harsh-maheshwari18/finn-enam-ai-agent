## Verified facts from the Prompt 1 spike (2026-10-27, local WSL machine)
- Yahoo chart API returns RELIANCE.NS daily data. **Verified.**
- NSE `api/corporate-announcements` returns JSON with PDF attachment links (TCS), no cookie needed from this IP. **Verified.**
- NSE `api/integrated-filing-results` returns latest-quarter iXBRL (TCS, quarter ended 30-Sep-2026). Parsed: Revenue 73,18,800 lakh, PBT 18,63,800 lakh, PAT 13,93,400 lakh, consolidated. Matches screener (₹73,188 / 18,638 / 13,934 cr). **Verified.**
- Older NSE `api/corporates-financial-results` XBRL stops at Dec-2024 for TCS, so the integrated-filing endpoint is required for recent quarters. **Verified.**
- The iXBRL integrated filing contains only the current quarter and YTD columns, **not** prior-quarter comparatives. QoQ/YoY need prior filings. **Verified.**
- screener.in company page is reachable; concall transcript and PPT links are present (BSE-hosted PDFs download via redirect). **Verified.**
- screener.in rate-limits: HTTP 429 after ~7 requests at 1.2s spacing. Needs throttle + cache. **Verified.**
- All 27 candidate tickers have NSE integrated-filing iXBRL results. **Verified.**
- BSE API directly: **Blocked** (Access Denied).
- No LLM API key is present in the environment. **Blocked until provided** (re-checked in Prompt 2, still absent).
- Reachability from a cloud host: **Not tested** in Prompt 1. Since measured from Render (see I).
